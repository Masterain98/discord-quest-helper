## Hotfix v0.10.2

- Fixed the issue that main windows icon at taskbar was overwritten by 1x1 pixel

## ✨ What's Changed in v0.10.1

1. Added support for manually simulating a game you are playing through Discord's native running-game detection.
    - You can now tell Discord that a specific game is running, even when it is not, so related quests can progress.
    - Added a "Running Games" view that shows what the app is currently reporting to Discord.
    - Added the ability to stop a simulated game and disconnect from Discord at any time.
2. Improved the way the app detects and reports games, and fixed several cases where game detection could fail or get stuck after launch.
3. On Windows, the app now runs in a more discreet way so Discord is less likely to notice it is a helper tool, making quest progress more reliable.
4. Refreshed and added translations for the new text.
5. Bumped default client config:
    - client version to `1.0.9254`
    - default client build number to `595897`
    - native build number to `88466`
