## What's New in 0.12.0

### Flexible quest completion notifications

1. Get quest completion notifications through System, Telegram, or Discord. Each channel reports delivery independently, and notification previews are localized.
2. Send notifications to a Custom Webhook using versioned JSON with task and queue details. Configure Bearer authentication and separate title and content templates for each event, use placeholders, test unsaved templates, and restore localized defaults available in all 16 languages.

### More control over Game Idle

Contributed by @klaus-2 (#221, #224).

3. Choose fixed or randomized ranges for play and rest durations.
4. Optionally simulate a game closing and reopening during a play cycle, with configurable timing and restart delay.
5. Keep a simulated game running for a chosen interval after a quest completes before the queue advances.
6. Improved simulated-game stop reliability. The app retries and verifies process termination, and keeps tracking a game when it is still running so cleanup can try again.

### Smoother Discord integration

7. Detect local Discord tokens across Windows, Linux, and macOS for Discord Stable, Canary, PTB, Equibop, Legcord, Vesktop, ArmCord, and WebCord. Detection now checks both common Local Storage and sessionData layouts (contributed by @Qyzom, #222).
8. Recover Discord API connections after network changes. Safe GET requests can retry once on a new connection, while other requests are not repeated (contributed by @ari92p, #211).
9. Improved Discord client discovery across updates and platforms, reducing stale entries while preserving manually selected clients when they are temporarily unavailable.
10. Improved CDP activity reporting by aligning client identity and heartbeat metadata with the current desktop client (contributed by @ccsimplyspolit, #218).
11. Check CDP clients and required native capabilities before injecting game or stream quest support. Unsupported clients such as Equibop are rejected before injection, and connection interruptions provide clearer reconnect guidance.

### Account details and interface improvements

12. View supported Discord account badges in the account menu, including games played, quests completed, and hours played. Use the shortcut beside eligible badges to open Game Simulator.
13. The floating Quest Progress panel stays within the app workspace when moved or resized.
14. Fixed external links so they open and copy their intended web addresses.
